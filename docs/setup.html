🔧 Getting Started

  • Power the ESP CYD using a USB-C cable
  • Connect to Wi-Fi via the setup webpage
  • Link the device to the SAM dashboard
  • Send test messages to confirm functionality

💡 Hardware Components

  • ESP CYD board
  • 2.8” TFT Display (SPI)
  • Optional: Speaker for notifications
  • 3D-printed yellow enclosure

📦 Software Architecture

SAM includes a Flask web dashboard and ESP firmware with:

  • WiFiManager for setup
  • Custom JSON message handling
  • TFT_eSPI for rendering
