Welcome to SAM

SAM (Send A Message) is a desktop companion device that receives messages from friends in real time. It runs on the ESP CYD, and displays messages, timestamps, and sender names with a friendly user interface.

Getting Started

  • Power the ESP CYD using USB-C
  • Connect to WiFi via the setup webpage
  • Link the device to the SAM dashboard
  • Send test messages to confirm functionality

Hardware Components

  • ESP CYD board
  • 2.8” TFT Display (SPI interface)
  • Speaker (optional for notifications)
  • 3D printed yellow enclosure (Smiley design)

Software Architecture

SAM runs a lightweight Flask-based backend for the web dashboard and uses WebSocket or HTTP polling to receive messages. On the ESP side:

  • WiFiManager for network setup
  • Custom JSON parser for message handling
  • TFT_eSPI library for display rendering

API Reference

Messages are sent to SAM via the following endpoint:

POST /api/sendMessage
Content-Type: application/json
{
  "sender": "John",
  "message": "Hello, Bob!",
  "timestamp": "2025-05-25T18:30:00Z"
}

🛠️ Build Your Own SAM

This guide walks you through building your own SAM device from scratch using the ESP CYD board.

📟 What is CYD?

CYD stands for Cheap Yellow Display, a community-driven project that combines an ESP32 microcontroller with a built-in 2.8" color TFT display — all packed into a yellow enclosure.

  • ESP32-based board with built-in Wi-Fi and Bluetooth
  • 2.8” SPI TFT display (320x240 resolution)
  • GPIO access for sensors, buttons, and buzzers
  • Open-source enclosure design with a cheerful yellow faceplate

I used this as a reference and it helped setup my CYD to build SAM!

🧾 Bill of Materials (BOM)

One of the goals of SAM is affordability, the entire build can be completed for under $20 USD, including all parts and the enclosure (if printed at home).

  • ESP32 CYD Board (Cheap Yellow Display) —> ~$13 USD. A compact ESP32 board with a 2.8” resistive touch TFT display built-in.
  • USB-C Cable —> ~$3 USD. Powers the device and allows firmware flashing.
  • M3 Brass Inserts + Screws —> ~$2 USD. Helps secure the screen inside the 3D printed case.
  • 3D Printable Enclosure Files —> (~80g PLA) Free to download. Print the smiley face case to complete the build.
