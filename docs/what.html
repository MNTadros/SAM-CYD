📟 What is CYD?

CYD stands for Cheap Yellow Display. It’s an ESP32 microcontroller with a built-in 2.8" TFT display inside a yellow enclosure.

  • ESP32 with Wi-Fi + Bluetooth
  • 2.8” SPI TFT (320x240)
  • GPIO access for sensors
  • Open-source 3D printed case

Reference: ESP32-Cheap-Yellow-Display

🧾 Bill of Materials (BOM)
