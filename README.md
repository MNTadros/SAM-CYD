# SAM – Send A Message

![SAM Banner](.\imgs\SAM_CYD.png)

**SAM (Send A Message)** is a friendly desktop IoT device powered by ESP32 CYD. It receives messages from a web dashboard and displays them with the sender’s name, time, and date, offering a personal way to stay connected.

## Features
- Receives messages via a custom web dashboard
- Displays sender name, message, date, and time
- ESP32 CYD with Wi-Fi for seamless communication
- Compact, cheerful yellow desktop design

## Tech Stack
- ESP32 CYD (Microcontroller)
- Wi-Fi (HTTP/REST or MQTT)
- Web dashboard (HTML/JS)

## Getting Started
1. Flash the ESP32 with the provided firmware
2. Set up Wi-Fi credentials
3. Use the dashboard to send messages
